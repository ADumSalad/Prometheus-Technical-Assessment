To run the frontend and backend, you need only open two command prompts/powershells/bash's. One that is connected to the frontend folder and one connected to the backend folder.

The frontend should connect to: ...\Prometheus-Technical-Assessment\StockApplication\frontend
The backend should connect to: ...\Prometheus-Technical-Assessment\StockApplication\backend

In both command prompts, run: npm run dev
The frontend should load the website automatically for you, and the backend should run so you can input in the frontend with results showing.

To run the system tests, run: npm test
Both the frontend and backend have seperate tests. Both can be run seperately.
